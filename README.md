
# Empereur, Citoyen, Esclave 🎴

Application web de jeu de cartes développée dans le cadre du Sprint 2 de la formation Développeur Web et Web Mobile.

## Description
Un jeu de duel contre l'ordinateur en 12 manches, avec gestion des profils de joueurs, système de scores et historique des parties.

## Technologies
- HTML5
- Tailwind CSS
- JavaScript
- LocalStorage
